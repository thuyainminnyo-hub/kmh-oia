# DhammaVerse AI — Integrated Pilot V0.1

**Mission:** Make Buddhist teachings understandable and practically learnable across languages and ages while preserving source accuracy, context, and respectful presentation.

## Configuration
- Audience: all audiences; age-appropriate presentation required
- Formats: bilingual web lessons, audio scripts, animation scripts, interactive exercises
- Languages: Burmese and English
- Budget: free services only; no paid API or compute dependency
- Parent architecture: KMH OIA runtime, Knowledge Registry, governed execution, trace and QA

## First lesson
Lesson 001: The Kālāma instruction (Aṅguttara Nikāya 3.65, Kesamuttisutta).

## Content layers (must never be silently merged)
1. Canonical source text and stable source identifier
2. Translator's rendering, translator named
3. Editorial explanation, clearly labelled
4. Modern educational adaptation, clearly labelled
5. Practice suggestion, clearly labelled and safety reviewed

## Audience safety
- All-audience does not mean one reading level: provide child, teen, and adult presentation variants.
- Do not present meditation as a substitute for medical or mental-health care.
- Do not diagnose, promise cures, or pressure religious belief or conversion.
- Include an opt-out / stop instruction for contemplative exercises if distress arises.
- Do not invent Buddha quotations or attribute modern wording to canonical texts.

## Free-first production
Static HTML/CSS/JS and versioned Markdown/JSON source files; local browser preview; GitHub Pages only after repository owner enables and approves it. Audio/video production remains optional and must not block the text-first pilot.

## Current status
Repository implementation and source references are committed on the feature branch. No public deployment, scholar approval, completed translation review, or production release is claimed.
