# ADR 0001 — KMH AION OS Master Identity

- **Status:** Accepted
- **Decision:** KMH AION OS
- **Expansion:** KMH Autonomous Intelligence & Operations Network
- **Date:** 2026-11-13

## Context

The existing KMH OIA repository is the executable foundation. The broader initiative needs a single master identity that can encompass agent orchestration, persistent memory, security, governance, evidence, and domain capabilities without creating duplicate runtimes.

## Decision

Use **KMH AION OS** as the master project identity and retain the existing repository name `kmh-oia` for continuity.

## Consequences

- The repository is not renamed in this decision.
- Existing KMH OIA runtime interfaces and tests remain authoritative until reviewed.
- New capabilities are added incrementally under the existing repository.
- Naming approval does not imply trademark, domain, or legal clearance.
